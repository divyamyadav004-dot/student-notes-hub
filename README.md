# student-notes-hub

Static educational website for Class 9-12, JEE, and NEET students.

## Structure
- `index.html` - Home page
- `pages/` - Notes, PYQs, Important Topics, Syllabus, About, Contact, Disclaimer pages
- `css/styles.css` - Shared responsive styling
- `js/main.js` - Shared navbar and form interactions
- `assets/` - Placeholder directory for images/PDF assets
